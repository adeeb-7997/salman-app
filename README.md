# ألعاب سلمان

تطبيق ألعاب للأطفال الصغار (من سنة ونصف): صور العائلة وأصواتها، والألوان، والرسم.

- ملفات التطبيق في مجلد `docs/`.
- كل الصور والأصوات تُحفظ داخل الجهاز (IndexedDB)، ولا شيء يُرفع لأي خادم.
- ملف APK يُبنى تلقائياً عبر GitHub Actions مع كل Commit.

## المراحل
1. ✅ الشاشة الرئيسية + وضع الوالدين (إضافة شخص بصورة وصوت)
2. ✅ لعبة «مين هذا؟» + الغميضة
3. ✅ البالونات + الرسم + أصوات الألوان
4. ✅ Capacitor + بناء APK + الأيقونة + مدة اللعب

## هيكل المشروع
```
docs/                     ← التطبيق (HTML/CSS/JS)
assets/                   ← صور الأيقونة وشاشة البداية
scripts/patch-android.sh  ← صلاحيات الميكروفون + رقم الإصدار + مفتاح التوقيع
.github/workflows/        ← بناء APK تلقائياً
package.json              ← حزم Capacitor
capacitor.config.json     ← اسم التطبيق ومعرّفه
```

## تنزيل APK
Actions ← آخر تشغيل ناجح ← Artifacts ← `salman-games-apk`

## Secrets المطلوبة
- `DEBUG_KEYSTORE_BASE64`: مفتاح التوقيع الثابت (احتفظ بنسخة منه، بدونه ما تقدر تحدّث التطبيق بدون حذفه)
