# ألعاب سلمان

تطبيق ألعاب للأطفال الصغار (من سنة ونصف): صور العائلة وأصواتها، والألوان، والأشكال.

- ملفات التطبيق في مجلد `docs/` (يُعرض على GitHub Pages، ويُستخدم لاحقاً في Capacitor).
- كل الصور والأصوات تُحفظ داخل الجهاز (IndexedDB)، ولا شيء يُرفع لأي خادم.
